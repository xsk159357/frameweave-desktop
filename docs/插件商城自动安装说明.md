# 插件商城自动安装说明

## 当前分发策略

免费插件使用 GitHub Release Asset 直连下载。FrameWeave 授权服务器只负责下载授权、下载记录和安装结果记录，不代理插件文件，避免占用授权服务器与中转站带宽。

## 客户端流程

1. 客户端请求 POST /api/market/items/{id}/download-auth。
2. 服务端返回 GitHub 直链、版本、文件大小、SHA-256 和最低客户端版本。
3. 客户端直接从 GitHub 下载 zip。
4. 客户端校验文件大小和 SHA-256。
5. 客户端通过本地安全安装接口解压并扫描节点。
6. 客户端刷新 specs，节点立即可用。
7. 客户端请求 POST /api/market/items/{id}/install-report 回报成功或失败。

## 安全约束

- 服务端不代理大文件。
- 客户端不包含 GitHub Token。
- 插件包必须是合法 zip，并通过现有 zip-slip 路径校验。
- 插件 manifest 必须符合声明式用户节点规范。
- SHA-256 不一致时禁止安装并回报失败。
- 免费插件不扣积分；付费字段和积分逻辑保留给后续 OSS/付费阶段。

## 接口

### 下载授权

POST /api/market/items/{id}/download-auth

请求：{item_id, token, client_version}；响应包含 download.url/download.sha256/download.size/version/type_id。

### 安装回报

POST /api/market/items/{id}/install-report

请求：{item_id, token, client_version, result, error}；result 当前使用 ok 或 failed。

## 后续迁移 OSS

用户量和下载量上升后，将 GitHub Release 文件同步到阿里云 OSS/CDN；客户端接口保持不变，只替换服务端返回的下载地址和签名策略。
