# FrameWeave 节点市场化（空壳分发）设计说明

> 日期：2026-10 ｜ 版本基线：v0.2.12 改造后
> 决策：**安装包只包含软件本体（引擎/画布/授权/商城），不捆绑任何节点；节点全部经商城/插件市场安装到用户数据目录。**

## 1. 目标

- 安装包瘦身、与节点版本解耦：发新节点/新模板不用重发客户端
- 客户端本体（引擎/资产/授权/商城）独立迭代，节点生态走商城分发
- 新装用户进入「空壳 + 引导装节点」体验，而非内置一堆节点

## 2. 改造点

| 文件 | 改动 |
|---|---|
| backend/packaging/frameweave-backend.spec | datas 移除 ('../user_nodes','user_nodes')，仅保留 voice_clone |
| backend/app/server.py | ① 删除「官方插件合并到用户目录」初始化块；② 删除「旧 _internal/user_nodes 迁移」死代码；③ /api/templates 返回空列表；④ from-template 统一 404（模板来自市场） |
| backend/app/declarative.py | 不变：USER_NODES_DIR 默认仍指向源码 backend/user_nodes（开发便利）；打包版由 server 启动时 set_user_nodes_dir → %APPDATA%/FrameWeave/user_nodes |
| web/src/App.tsx | ① 初始化不再尝试内置模板（直接建空工作流）；② 模板弹层空态引导去商城；③ 新增 fw-open-market 事件监听 |
| web/src/Canvas.tsx | ① specs 为空时显示「节点库为空」引导面板（去商城/导入插件/刷新节点）；② 新增 fw-nodes-installed 监听 → 安装后自动刷新 specs |
| web/src/Sidebar.tsx | 节点库空态文案区分「节点库为空」vs「无匹配」 |
| web/src/store.ts | setSpecs 时广播 fw-nodes-installed（画布/侧栏/右键菜单联动刷新） |
| backend/app/templates.py | 保留文件（oneclick 模板逻辑），不参与打包；未来作为商城模板条目源 |

## 3. 行为矩阵（改造后）

| 场景 | 行为 |
|---|---|
| 全新安装（无节点） | 空画布中央引导面板：「去商城安装节点 / 导入节点插件 / 刷新节点」 |
| 商城安装节点 | install → reload → specs 更新 → fw-nodes-installed 广播 → 空态消失，节点出现在侧栏/右键菜单 |
| 本地 zip 导入插件 | 同商城（PluginPanel 已 reload + setSpecs） |
| 打开含节点的工作流但节点未装 | 节点卡 title 回退显示 type_id（Canvas 现有逻辑），运行时报「节点类型未注册」——引导先装节点 |
| /api/templates | 空列表（模板来自市场，未安装为 0） |
| /api/workflows/from-template/{id} | 404「模板未安装」 |
