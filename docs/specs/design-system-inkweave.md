# FrameWeave · 设计系统「墨织 INKWEAVE」v2.0

> 适用范围：桌面应用（Electron + React）、运营后台 `houtai.frameweave.top`、官网 `frameweave.top`、安装器与图标资产。
> 状态：2026-10 全量重设计基线。旧「霜幕 / 流光织机」令牌全部废止。

---

## 1. 设计立场

拾帧是一个**专业视频创作工具**，不是聊天式 AI 产品。界面首先服务于「长时间、高强度、低干扰的剪辑与编排」，其次才表达品牌。

- **编辑台，不是控制台**：信息密度高、层级靠留白与字号区分，而不是靠卡片堆叠和发光。
- **黑白灰是主角，黄铜是标点**：强调色只出现在主操作、选中态、运行进度与品牌符号上，绝不大面积铺色。
- **取景框语言**：四角括号、时间码、帧格、细线网格 —— 来自摄影机取景器与胶片，而不是霓虹/玻璃/渐变。
- **克制的动效**：120–200ms，位移 ≤ 8px，只用于状态变化；无弹跳、无光晕、无呼吸灯。

## 4. 形状与间距

- 圆角：`--r-xs 2px`、`--r-sm 4px`、`--r-md 6px`、`--r-lg 8px`、`--r-xl 12px`。按钮/输入 4–6px，卡片 6px，弹层 10px。禁止 16px+ 的“软糖圆角”。
- 间距：4 的倍数。面板内边距 12/16，列表行高 30–34。
- 阴影：只保留两层
  - `--shadow-1 0 1px 2px rgba(0,0,0,.35)`（贴地层）
  - `--shadow-2 0 18px 50px -12px rgba(0,0,0,.65)`（浮层/弹窗）
- 禁止：玻璃模糊、彩色投影、内发光、渐变边框。

- 时间线只在选中含 segments 资产的节点时展开。

## 6. 组件规范

- **按钮**：高度 28（sm）/ 32（md）；主按钮黄铜实底 + 黑字；次按钮 1px 线框透明底；幽灵按钮无框 hover 底色。禁用态 40% 透明。
- **输入**：高 30，底色 `--ink-600`，1px `--line`，聚焦时边框黄铜 + 2px `--brass-soft` 环，无发光。
- **标签页**：文字 + 2px 底部黄铜短线；未选中 `--paper-faint`。
- **节点卡**：240 宽，`--ink-800` 底 + `--line` 描边 + 4px 圆角；标题左缘 2px 分类色条；端口 7px 圆点；运行中顶部 2px 黄铜进度；失败红边；缓存命中虚线边。
- **表格/列表**：行高 32，hover `--ink-500`，选中 `--brass-soft` + 左侧 2px 黄铜条。
- **弹层**：遮罩 `rgba(4,5,6,.66)`；面板 `--ink-800` + `--line-strong` + 10px 圆角 + `--shadow-2`；标题 14/700，副标题 12 `--paper-dim`。
- **Toast**：左下，`--ink-700` 底，左侧 2px 语义色条，10px 圆角。

- 应用图标：石墨底圆角方块 + 黄铜 `F` 破出米白取景框（两角括号）。

## 8. 文案语气

短、具体、动词开头。避免“赋能 / 一站式 / 释放创造力”等空话。
示例：`一键出片`、`仅跑下游`、`保存工作流`、`节点库为空`、`从第一个节点开始`。
