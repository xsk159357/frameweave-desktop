## 已修复（本轮）

### 后端安全
1. **本地鉴权全面加严**（server.py local_token_guard）：
   - secrets / export / assets 全部端点要求 `X-FW-Local-Token`；
   - 写操作（POST/PUT/DELETE）覆盖 workflows / market / user_nodes / util / **draft**；
   - /api/auth/*、health、/ws 保持开放（登录前置）。

   - RequestValidationError → 规范 422；畸形 JSON → 400；未捕获异常 → 规范 500（不泄露内部细节）。
