# GIT 提交约定（2026-10-06）

## 铁律
- **每次改动完成并验证后都要提交到 git 分支**（用户明确要求，长期有效）。
- **绝不 force-push / --force-with-lease 也不可用时**（remote 历史发散场景）：origin/main
  目前只有一个空的 README "Initial commit"（与本地无共同祖先），若需将本地真实历史推上
  origin/main 属覆盖空初始提交，须先经用户确认。
- 提交前先 `git status` 核对清单：`.work`/`.work*` 备份、`backend/data`、`.tmp`、
  `web/dist`、`release/`、`.env` 等已被 .gitignore 排除，不得入库。

## 提交方式
- 按主题分组多个语义化 commit（feat/fix/chore/docs），不使用 `git add -A` 一把梭（历史留痕清晰）。
- 中文文件名路径加引号：`git add 'docs/xxxx.md'`。
- 本轮提交示例：
  1. `feat(cloud): 云端授权 E6-E10 全链路…`
  2. `fix(engine,web): 商城发布导出入口 + 失败回滚/孤儿清理 + 安全实测闭环`
  3. `chore: 历史累积 UI/脚本/构建流水线 + 提交约定`
