## 3. 问题 A：商城 download-auth 返回 item_not_found（待服务器侧排查）

**现象**：对官方节点（如 core-load-video）调 /api/market/download-auth，云端返回 {"ok":false,"code":"item_not_found"}。

**诊断过程（全部实测）**：
1. 客户端直连云端 HTTP → item_not_found
2. 服务器本机直连 127.0.0.1:8789（绕过 OpenResty）→ item_not_found
3. 服务器上 import cloud_server 直接调用 _market_item → None
4. 但 market_items.json 磁盘文件里键存在（json.load 后 k=='core-load-video' 为 True）
5. 服务器 venv 环境直调 _market_item → None；但同环境 `'core-load-video' in data` 为 True、`.get()` 失败——键含不可见字符或 MARKET_FILE 解析不一致（需服务器端查服务进程 CLOUD_DB/MARKET_FILE 实际指向）

**判定**：云端服务进程读到的市场数据与磁盘文件不一致（服务进程启动时可能加载了旧 market 数据，或 MARKET_FILE 解析路径与预期不同）。已重启服务仍复现。

**临时影响**：官方插件从商城自动安装暂不可用；客户端仍可手动导入插件 zip（PluginPanel）或用直链手动下载安装。
