## 1. 审计清单（逐项结论）

| # | 检查项 | 结论 | 处置 |
|---|---|---|---|
| A1 | 敏感字段泄露：管理密钥/卡密密钥/签名密钥 | 管理密钥与卡密密钥缺省为空，**空串可绕过管理登录**（A1-1 高危）；卡密 HMAC 空密钥可伪造（A1-2 高危）；VERIFY_SECRET 默认常量内嵌源码且与客户端 obf 默认一致（A1-3 提示） | 已修复 A1-1；A1-2/A1-3 启动告警 + 文档强制要求（见 §4 剩余风险） |
| A2 | 管理员会话/CSRF | token 存 localStorage（XSS 面）；CSRF 由 body-token 机制天然缓解；t2 重设计已消除 onclick 属性注入 XSS（`esc(qs(id))` + 缓存查表） | t2 已消除（已验证源码）；localStorage 列为剩余风险 |

| A4 | 错误信息 | ops 代理错误透出异常类型与内部路径；通用错误处理正确（500 泛化） | 已修复：ops 错误泛化，回环地址白名单阻断 file:// SSRF |

| A6 | 路径/文件写入 | 用户可控 IP 由服务端 socket 覆盖；市场文件仅管理员写；`_clean_key` 净化键；无任意文件读写点 | 通过 |
| A7 | 生产部署一致性 | 服务绑定默认 127.0.0.1 正确；更新脚本上传无完整性校验（半包风险）；python runner 依赖裸 `python`（0.3.5 教训） | 已修复：远端 sha256 校验；runner 自动回退 venv |
| A8 | CORS/反代假设 | 服务不设 CORS 头（同源安全）；反代 XFF 未处理（同 A3） | 已修复 A3；CORS 维持不放行 |
| A9 | 日志脱敏 | dev 邮件模式完整验证码打印进 stdout（误配时进生产 journal）；请求日志关闭 | 已修复：默认掩码，`FRAMEWEAVE_DEV_MAIL_VERBOSE=1` 显式开启完整码 |
| A10 | 请求体/连接 DoS | 无请求体上限；ThreadingHTTPServer 非 daemon 线程 | 已修复：1MB 上限 413；daemon_threads |
| A11 | 安全响应头 | 后台页无 X-Frame-Options/CSP/nosniff/no-store | 已修复 |

## 2. 修复清单（已实施）

### 2.1 `backend/cloud_server.py`
1. **管理登录空密钥拒绝**（A1-1）：未配置管理密钥时返回 `code:not_configured`，杜绝 `hmac.compare_digest('','')` 绕过。
2. **启动告警**（A1-2/A1-3/部署）：CARD_SECRET 未设、管理密钥未配置、未开 IP 白名单、TRUST_XFF 启用时分别打 WARN/INFO；不阻断启动（保持测试与既有部署契约）。
3. **反代 IP 还原**（A3/A8）：`TRUST_XFF` 环境开关 + `_peer_ip()`（仅回环对端信任 X-Forwarded-For 最右项），使 IP 限流与管理白名单在反代后真实生效；默认关闭。
4. **ops 代理加固**（A4）：`ops_base` 仅允许 `http(s)://127.0.0.1|localhost` 回环；通用错误不再透出异常类型/内部路径（HTTP 状态码分支保留）。
5. **备份/恢复**（A5）：备份补 `password_hash/salt/cards_used`（恢复后账号仍可登录）；备份不含会话 token；恢复事务化（失败整体回滚）、恢复前自动生成 `backups/pre_restore_*.db` 快照（保留 10 份）、恢复后重置 token（用户需重登录）。
6. **日志脱敏**（A9）：dev 邮件打印默认 `****<后两位>`；`FRAMEWEAVE_DEV_MAIL_VERBOSE=1` 显式输出完整码供本地 E2E。
7. **请求体上限与线程**（A10）：>1MB 返回 `413 {"ok":false,"code":"body_too_large"}`（负值/非法 Content-Length 按 0 处理）；`ThreadingHTTPServer.daemon_threads=True`。
8. **安全响应头**（A11）：JSON/HTML 统一 `X-Content-Type-Options: nosniff` + `Cache-Control: no-store`；后台页另加 `X-Frame-Options: DENY`、`Referrer-Policy: no-referrer`、CSP（`frame-ancestors 'none'; base-uri 'none'; form-action 'none'` 等）。

### 2.2 `backend/admin.html`
- 无需改动：t2 重设计已消除存储型 XSS 向量（编辑/上下架按钮仅传条目 id，经 `esc(qs())` 双保险属性编码 + 缓存查表取条目；一切不可信文本走 `esc()` 文本节点渲染）。已验证源码（`renderMarket` 行 642 等）。

### 2.3 部署脚本（均恢复 UTF-8 BOM，PS5.1 兼容）

- `scripts/upload-release-korea.ps1`：`.tmp/kr_fix_upload.py` **遗留明文口令回退默认禁用**（`-AllowLegacyFallback` 显式启用并打印高危告警）；上传后逐文件 sha256 核对。
- `scripts/release-github-korea.ps1`：同一遗留回退改为显式开关。

## 4. 剩余风险（需用户/队长处置）

1. **【严重·待办】明文根口令落盘**：`.tmp/` 约 70 个脚本（含 `kr_fix_upload.py` 等，均 gitignore）硬编码韩国服务器 root 口令。已做：发布脚本不再自动读取；**待办：① 轮换该口令；② 迁移 SSH 密钥 `~/.ssh/frameweave_auth` 并禁用服务器密码登录；③ 用户确认后隔离/删除这些脚本**（AGENTS.md 删除纪律：须用户确认）。
2. **【中】VERIFY_SECRET 内嵌默认**：签名密钥默认值与客户端 obf 默认一致，客户端可提取 → 响应签名为纵深防御/防篡改提示，非强认证；最终授权判定以服务端为准（token/过期/禁用等服务端断言）。生产若需升级，须同步客户端密钥通道（改版发布流程）。
3. **【中】管理 token 存 localStorage**：XSS 全消除后风险大降；仍建议后续改 sessionStorage 或 8h 会话绑定（变更 UX，需产品确认，本次未动）。
4. **【中】商城付费下载积分扣减存在读-改-写竞态**（并发双花）：t1 正在原子化修复（`market_download_auth` 原子扣积分 + 文件锁），不在本次实施范围；修复后须回归下载授权契约测试。
5. **【低】备份 JSON 含 admin_settings（admin_key/ops_token/smtp）**：仅为管理员浏览器下载，恢复必需；建议备份文件落服务器侧加密存储（后续迭代）。
6. **【低】管理员界面-审计日志含邮箱/IP**：管理后台功能必需；注意不得外发截图/导出物。
7. **【低】`backend/app/email_service.py` 本地桩 dev-mail 仍打印完整码**：仅本地后端（不上云），如需上云按 §2.1-6 同样处理。
