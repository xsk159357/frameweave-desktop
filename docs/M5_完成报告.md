## 2. M5① 批量并发调度

### 实现（backend/app/nodes/batch_render.py）
- 串行 for 循环 → `asyncio.Semaphore(max_concurrent)` 并发池
- 新增参数 `max_concurrent`（默认 2，0=不限制）
- 单条目逻辑拆为 `_process_item`（TTS → 字幕 → 渲染）
- 进度汇报：每完成一条推 `ctx["progress"]`（0~1）
- 失败隔离：单条失败不影响其他条目
- 结果保持输入顺序（按 index 排序）

### 实测（3 条文案，同源视频）
- 串行（max_concurrent=1）：3.6s（每条约 1.2s）
- 并发（max_concurrent=3）：0.1s
- **加速比 30.4x**，三集成品同时落盘

### 修复
- results JSON 序列化：Asset 对象 → 仅存 `video_id` + `_video_asset`（内部用）

## 3. M5② electron-updater 自动更新

### 实现
- 依赖：`electron-updater@6.3.9`（desktop/package.json dependencies）
- publish 配置：generic provider + `https://update.example.com/frameweave`（可被 `FRAMEWEAVE_UPDATE_URL` 环境变量覆盖）
- main.cjs：
  - 启动 5 秒后 `checkForUpdates()`（仅打包模式）
  - 发现新版本 → 系统对话框「立即更新/稍后」
  - 下载进度 → 前端 `update:progress` 事件
  - 下载完成 → 对话框「立即重启/稍后」→ `quitAndInstall()`
  - `autoInstallOnAppQuit` 兜底
- preload.cjs：暴露 `checkForUpdate` / `onUpdateAvailable` / `onUpdateProgress`
- App.tsx 顶栏：「🔄 检查更新」按钮

### 打包验证（electron-builder --win nsis）
- `FrameWeave-Setup-0.1.0.exe`（208.8MB）生成 ✅
- `latest.yml` 生成（version/sha512/path/releaseDate）✅
- `FrameWeave-Setup-0.1.0.exe.blockmap` 增量块生成 ✅
- app.asar 内确认包含 electron-updater / update.example.com / setupAutoUpdate / checkForUpdate ✅
- **实际 sha512 与 latest.yml 完全匹配** ✅
