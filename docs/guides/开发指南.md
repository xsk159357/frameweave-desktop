# 拾帧 FrameWeave 开发指南（M0）

> 本文档为 README「快速开始」完整版（原 `docs/M0_开发指南.md`，2026-10-14 文档分层时落位 `docs/guides/`）。
> 适用版本：main @ v0.3.0 / 0.3.1 开发中。技术栈四层：desktop（Electron 33）/ web（React 18 + Vite + @xyflow）/ backend（Python 3.14 + FastAPI）/ cloud（cloud_server 云授权）。

## 1. 目录结构

```
FrameWeave/
├── backend/     FastAPI 本地服务（执行引擎 + 节点 + 插件/商城/授权网关）
├── web/         Vite + React 前端（@xyflow/react 画布）
├── desktop/     Electron 壳（main.cjs + preload.cjs，NSIS 打包）
├── scripts/     构建 / 发布 / 校验脚本（见 §4）
├── docs/        项目文档（分层：guides 指南 / specs 规范 / plans 方案 / records 记录 / reports 报告）
├── release/     安装包输出（.gitignore，不入库）
└── certs/       代码签名证书（内部使用，不提交）
```

## 2. 快速开始（源码运行）

### 2.1 后端（必须先启动）

```powershell
cd backend
# 依赖：Python 3.14 虚拟环境（项目 embedded Python 或 python -m venv）
python main.py
# 默认监听 http://127.0.0.1:8788 （可用环境变量 FRAMEWEAVE_PORT 覆盖）
```

- 源码模式跳过打包自检；frozen 打包版先做 integrity 自检再启动。
- 附加入口：`--fw-worker <job>`（worker 子进程模式）、`--env-check`（插件环境检查 CLI）。

### 2.2 前端（开发模式）

```powershell
cd web
npm install
npm run dev        # Vite dev server（默认 5173，代理 /api → 8788）
```

### 2.3 前端（构建 + 本地预览）

```powershell
cd web
npm run build
cd ..
node dev-server.cjs   # 静态服务 http://127.0.0.1:5180，/api 代理 → 127.0.0.1:8788
```

### 2.4 桌面壳（Electron）

```powershell
cd desktop
npm install
npm start          # electron . （拉起本地后端 + 加载 web/dist 或 dev server）
```

## 3. 测试

- 后端验收测试：`backend/tests_t2~t7`（共 8 个脚本，逐个 `python tests_tX_*.py` 运行；无统一 pytest 配置）。
- E2E：`web` 下 Playwright 脚本（`smoke.mjs`、`market_*e2e*.mjs`）。

## 4. 构建 / 发布

| 脚本 | 作用 |
|---|---|
| `scripts/build-backend.ps1` | PyArmor 混淆 + PyInstaller 增量打包 → `backend/packaging/dist/backend-dist` |
| `scripts/build-installer.ps1` | Vite build + 契约检查 + electron-builder NSIS + makensis → `release/` |
| `scripts/publish.ps1` | 代码签名 + 发布（内部使用；含默认证书密码回退，外发前需脱敏） |
| `scripts/check_release.ps1` | 发布产物 SHA512 校验 |

一键打包：`cd desktop; npm run pack`（build:web → integrity → electron-builder --win nsis）。
