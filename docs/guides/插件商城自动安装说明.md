# 插件商城自动安装说明

## 当前分发策略（2026-10-14 现状）

官方插件**统一托管在韩国授权服务器** `https://shouquan.frameweave.top/plugins/`，不再以 GitHub Release 作为客户端插件下载源。韩国服务器站点 `plugins/` 实测已有 40+ 官方 zip 与 ed25519 `.sig` 签名文件；授权服务 `/opt/frameweave-cloud/market_items.json` 的 `download_url` 指向该域名。

三通道统一拓扑：

- 授权：`https://shouquan.frameweave.top/api/` → `frameweave-cloud.service` → 127.0.0.1:8789
- 更新：`https://shouquan.frameweave.top/update/` → latest.yml + 安装包 + blockmap
- 插件：`https://shouquan.frameweave.top/plugins/` → 官方插件 zip + `.sig`

## 客户端流程

1. 客户端请求 `POST /api/market/items/{id}/download-auth`。
2. 服务端读取韩国服务器本地 `market_items.json`，返回韩国插件直链、版本、文件大小、SHA-256 和最低客户端版本。
3. 客户端直接从 `shouquan.frameweave.top/plugins/` 下载 zip（不依赖 GitHub Token）。
4. 客户端校验文件大小和 SHA-256（签名文件由服务端/安装器链路保留用于验签）。
5. 客户端通过本地安全安装接口解压并扫描节点。
6. 客户端刷新 specs，节点立即可用。
7. 客户端请求 `POST /api/market/items/{id}/install-report` 回报成功或失败。

## 韩国服务器文件布局

```text
/opt/frameweave-cloud/
├── cloud_server.py       # 授权 + 商城 API（systemd: frameweave-cloud.service）
├── cloud.env              # DirectMail / 管理密钥（仅服务器）
└── market_items.json      # 商城元数据与 plugins download_url

/opt/1panel/www/sites/shouquan.frameweave.top/
├── update/                # latest.yml + FrameWeave-Setup-*.exe + *.blockmap
├── plugins/               # 官方插件 *.zip + *.zip.sig
├── index/models_registry.json
└── proxy/api.conf         # /api/、/admin/ → 127.0.0.1:8789
```

## 发布与同步

- 官方插件构建源：`frameweave-plugins/`（packages/dist/docs/sdk）。
- 生成并签名插件：使用 `frameweave-plugins/sdk/` 与 `scripts/package-official-plugins.ps1`。
- 发布同步：将 `dist/*.zip` 与 `dist/*.sig` 上传到韩国服务器 `plugins/`，同步更新服务器端 `market_items.json` 的 `sha256`、`sig_sha256`、`size`、`version` 与 `download_url`。
- 客户端更新发布：将 `release/<version>/` 三件套上传到韩国服务器 `update/`；`latest.yml` 必须与 exe 的 SHA-512、大小一致。

## 安全约束

- 韩国服务器 `cloud.env` 中的 DirectMail、卡密管理密钥、签名私钥不得进入客户端、仓库、GitHub 或聊天记录。
- 插件包必须是合法 zip，并通过现有 zip-slip 路径校验。
- 插件 manifest 必须符合声明式用户节点规范；官方包保留 ed25519 `.sig`。
- SHA-256 或签名不一致时禁止安装并回报失败。
- 服务器目录禁止开启目录列表；具体文件直链必须公网验证 200。
- 免费插件不扣积分；付费字段和积分逻辑保留。

## 接口

### 下载授权

`POST /api/market/items/{id}/download-auth`

请求：`{item_id, token, client_version}`；响应包含 `download.url/download.sha256/download.size/version/type_id`。

### 安装回报

`POST /api/market/items/{id}/install-report`

请求：`{item_id, token, client_version, result, error}`；`result` 当前使用 `ok` 或 `failed`。
