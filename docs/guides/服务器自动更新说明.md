密码来源（优先级从高到低）：

1. 环境变量 `FW_SERVER_PASSWORD`（韩国别名 `FW_KOREA_PASSWORD`，单次使用）
2. 本机受保护文件 `%USERPROFILE%\.frameweave\server.env`，内容 `FW_SERVER_PASSWORD=...`
3. SSH 密钥 `%USERPROFILE%\.ssh\frameweave_auth`（推荐，无需密码）

> ⚠️ 2026-10-14 实测：`server.env` 的 `FW_SERVER_PASSWORD` 对应**旧日本中转**（历史遗留），**非韩国服务器密码**。2026-10-17 t3 加固后：部署脚本（update-cloud-auth.ps1 凭据仅 env/server.env/SSH 密钥；upload-release-korea.ps1、release-github-korea.ps1 的 `.tmp/kr_fix_upload.py` 遗留明文口令回退**默认禁用**，需显式 `-AllowLegacyFallback`）。新会话请：设 `env FW_KOREA_PASSWORD`（单次）或迁移 SSH 密钥 `~/.ssh/frameweave_auth`。

**强制待办（安全审计结论）**：韩国服务器 root 口令曾在 `.tmp/` 约 70 个脚本明文落盘——**必须轮换口令、迁移 SSH 密钥并禁用密码登录**；`.tmp/` 内明文口令脚本经用户确认后隔离/删除。

## 2. 自动更新命令

更新授权服务端并完整自检：

```powershell
pwsh scripts/update-cloud-auth.ps1
```

仅检查服务器状态（不更新）：

```powershell
pwsh scripts/update-cloud-auth.ps1 -CheckOnly
```

脚本执行：

1. 备份远端 `cloud_server.py` 到 `/opt/frameweave-cloud/backups/<时间戳>/`
2. 上传本地 `backend/cloud_server.py`（及存在的 `backend/admin.html`）
3. **远端 sha256 完整性校验**（2026-10-17 t3 新增：与本地逐字节比对，防半包/截断上传，不匹配即中止不重启）
4. 远端 `py_compile` 校验
5. `systemctl restart` 并确认 active
6. `/api/health` 校验（protocol_version=3、auth_revision=email-code-v2）
7. `send-code` 对非 QQ 邮箱的拒绝自检
8. 任一失败即中止并输出原因

> 部署前请按《云端授权与发布规范》§14 核对 `cloud.env` 环境变量与 OpenResty 反代配置（FRAMEWEAVE_TRUST_XFF 等）。
