密码来源（优先级从高到低）：

1. 环境变量 `FW_SERVER_PASSWORD`（韩国别名 `FW_KOREA_PASSWORD`，单次使用）
2. 本机受保护文件 `%USERPROFILE%\.frameweave\server.env`，内容 `FW_SERVER_PASSWORD=...`
3. SSH 密钥 `%USERPROFILE%\.ssh\frameweave_auth`（推荐，无需密码）

> ⚠️ 2026-10-14 实测：`server.env` 的 `FW_SERVER_PASSWORD` 对应**旧日本中转**（历史遗留），**非韩国服务器密码**——韩国授权服务器 43.108.23.200 的可信密码保留在 `.tmp/kr_fix_upload.py`（0.3.1 发布实测）。`update-cloud-auth.ps1` 默认 Server 已为 `43.108.23.200`，但凭据解析仍读 `FW_SERVER_PASSWORD`，新会话须先核实两处密码一致性，或迁移到 SSH 密钥。

推荐尽快切换到 SSH 密钥并禁用密码登录；曾暴露的密码必须轮换。

## 2. 自动更新命令

更新授权服务端并完整自检：

```powershell
pwsh scripts/update-cloud-auth.ps1
```

仅检查服务器状态（不更新）：

```powershell
pwsh scripts/update-cloud-auth.ps1 -CheckOnly
```

脚本执行：

1. 备份远端 `cloud_server.py` 到 `/opt/frameweave-cloud/backups/<时间戳>/`
2. 上传本地 `backend/cloud_server.py`
3. 远端 `py_compile` 校验
4. `systemctl restart` 并确认 active
5. `/api/health` 校验（protocol_version=3、auth_revision=email-code-v2）
6. `send-code` 对非 QQ 邮箱的拒绝自检
7. 任一失败即中止并输出原因

1. 修改本地 `backend/cloud_server.py`（或客户端相关代码）
2. `python -m py_compile` 本地校验
