## 2. 轮换步骤（需维护窗口，约 10 分钟）

> 以下命令在**你自己的终端**执行；本仓库任何脚本都不再内置口令。

### 2.1 服务器 root 口令

```bash
# 1) 登录（用当前口令，仅本次交互输入，不要写进脚本）
ssh root@43.108.23.200

# 2) 改口令（交互输入新口令，建议 20 位随机）
passwd root

# 3) 更稳妥：同时改为仅密钥登录（口令仅作应急）
mkdir -p ~/.ssh && chmod 700 ~/.ssh
# 本地：ssh-keygen -t ed25519 -f ~/.ssh/frameweave_auth -C frameweave-deploy
# 本地：ssh-copy-id -i ~/.ssh/frameweave_auth.pub root@43.108.23.200
# 服务器：确认密钥可登录后，再编辑 /etc/ssh/sshd_config
#   PasswordAuthentication no
#   PermitRootLogin prohibit-password
systemctl reload sshd   # 或 systemctl reload ssh
```

### 2.2 X-UI 面板口令

```bash
# 面板入口若为 /xui 或独立端口，按 1panel 容器路径进入：
docker exec -it <xui容器> /app/x-ui setting -username <新用户名> -password '<新口令>'
docker restart <xui容器>
```
（容器名以 `docker ps | grep x-ui` 实际输出为准。）

### 2.3 客户端/发布侧凭据落点

| 用途 | 变量 | 落点 |
|---|---|---|
| 部署脚本 SSH | `FW_SERVER_PASSWORD` / `FW_KOREA_PASSWORD` | 环境变量；或 `%USERPROFILE%\.frameweave\server.env`（`update-cloud-auth.ps1` 读取） |
| SSH 密钥 | — | `%USERPROFILE%\.ssh\frameweave_auth`（`update-cloud-auth.ps1` 优先用密钥） |
| 云端卡密 HMAC | `FRAMEWEAVE_CARD_SECRET` | 服务器 `/opt/frameweave-cloud/cloud.env` |
| auth 响应验签 | `FRAMEWEAVE_VERIFY_SECRET` | 同上（客户端与服务端共用） |
| 管理后台 | `FRAMEWEAVE_ADMIN_KEY` | 同上 + `FRAMEWEAVE_ADMIN_ALLOW_IPS` 白名单 |
| 开发 PFX | `FRAMEWEAVE_PFX_PASSWORD` | `publish.ps1` 已支持环境变量；内置默认值仅对 dev 自签证书有效 |

改完 `cloud.env` 后：`systemctl restart frameweave-cloud`，再跑
`powershell -File scripts/update-cloud-auth.ps1 -DryRun`（若脚本无 DryRun 则直接按手册 §14 执行）验证健康。
