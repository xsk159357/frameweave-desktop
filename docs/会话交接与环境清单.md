## VM
- 当前 VMX：D:/虚拟机/测试.vmx
- vmrun：D:/VMware-17.5.1 安装包+秘钥/vmrun.exe
- Guest 用户：Administrator
- Guest 密码：不持久化；本轮用户提供 1234
- NAT 网段：VMnet8，通常 192.168.88.0/24；当前曾获得 192.168.88.129，需每次用 vmrun getGuestIPAddress 实测。
- 安装路径：C:/Users/Administrator/AppData/Local/Programs/FrameWeave/FrameWeave.exe
- 关键经验：vmrun 1.17 只接受 -interactive/-noWait，不接受 -active-window；PowerShell 脚本必须 UTF-8 BOM，否则中文路径会被 PowerShell 5.1 按 ANSI 误解析。
- 安装前必须结束 FrameWeave.exe、frameweave-backend.exe、FrameWeave-Setup-latest.exe；NSIS 曾因旧进程占用而无法写入。
- Guest 脚本执行通道不稳定；不能把 verify-vm.ps1 exit 0 当作全部通过，必须读取实际结果文件/进程/health。
