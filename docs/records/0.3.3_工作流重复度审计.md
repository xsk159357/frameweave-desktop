### 可保留组 B：批量与高光

| 条目 | 节点/边 | 定位 |
|---|---:|---|
| `wf-wf_batch_narration` / 批量影视解说 | 4/5 | 多视频批量分析 + 高光 + TTS + 竖屏输出 |
| `wf-fw_batch_mixcut` / 批量精彩混剪 | 3/3 | 多视频批量编排 + 高光 + 混剪，不强调旁白 |
| `wf-wf_highlight_mix` / 剧情高光混剪 | 5/6 | 单视频场景检测 + ASR + 高光混剪 |

三者共享高光/混剪能力，但输入模式和输出目的不同，建议保留并改名强化差异：
- 批量影视解说 → **批量解说短视频**
- 批量精彩混剪 → **批量高光混剪**
- 剧情高光混剪 → **剧情高光短视频**
