## 2. M11① 后端 run_history

### 实现（engine.py + server.py）
- GraphNode 新增 `run_history` 字段（List[Dict]，保留最近 20 条）
- 新增 `_append_history(node, status)` 辅助函数：
  - 记录 `{time, status, params, cache_key, error}`
  - 超出 20 条自动裁剪
- **触发点**：SUCCESS 分支 + CACHED 分支各记录一条
- to_dict / from_dict 双向序列化；server.py PUT 保存时继承历史（不丢失）

### 语义说明
- 真正执行（_run_one 成功 或 缓存命中）才记录；参数未变且节点已成功时再次 run 直通不产生新记录（合理：无运行动作）
- 与 M9 last_params（单快照）互补：last_params 高亮「当前 vs 上次」，run_history 回溯「多次运行」

## 3. M11② 前端运行历史面板

## 5. 已知边界
- 历史上限 20 条/节点（防无限增长）
- 缓存直通不记录（无运行动作）——如需记录缓存命中次数需另做计数器
- 失败运行不记录（FAILED 分支未加 _append_history——失败详情在 error 字段实时可见）
  - 如需记录失败历史可补：node.status == FAILED 时 _append_history(node, "failed")
