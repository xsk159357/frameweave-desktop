## 2. M4① 多格式导出（FCPXML）

### 实现
- `_build_fcpxml`：FCPXML 1.9 结构（resources + library/event/project/sequence + spine）

- 三层轨道：视频(asset-clip) / 音频(audio lane) / 字幕(title + text-style)
- spec 新增 `fcpxml` 输出端口 + `format` 选项（jianying/prxml/edl/fcpxml/all）
- 落盘 `草稿名.fcpxml`

### 验证

## 4. M4③ 密钥本机加密存储（DPAPI）

### 实现
- `backend/app/secrets.py`：ctypes 调 Crypt32.dll（CryptProtectData/UnprotectData）
  - 加密绑定当前 Windows 用户，换机/换用户不可解
  - 密文 base64 存 %APPDATA%/FrameWeave/secrets.json（打包）/ backend/data（源码）
  - 原子写入（tmp + os.replace）
- API：GET/PUT/DELETE /api/secrets，GET /api/secrets/{name} 仅回环解密
- 节点支持 `@secret:名称` 引用（ai_narrate / tts cloud / translate）
- 前端 ParamPanel：api_key 输入框改 password + 「🔐 加密存入本机保险箱」按钮

### 验证
- 写入→读出一致 ✅；密文文件不含明文 ✅；删除 ✅
- 真实 Key（ameaao）已密文入库，PUT/GET/列表全通
