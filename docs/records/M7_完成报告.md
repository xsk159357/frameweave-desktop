## 2. M7① 后端单节点 API

### 新增端点
`POST /api/workflows/{wfid}/nodes/{nid}/reset`

| 参数 | 说明 |
|---|---|
| 默认 | 状态→pending，清空 asset_ids / error / progress（运行时重算） |
| `force: true` | 同时清除该节点缓存键（`engine.invalidate_cache`），下次运行**强制重算** |

### engine 增强
- 新增 `Engine.invalidate_cache(cache_key)`：删缓存条目并持久化（cache_index.json）

### 关键发现
- 引擎缓存是**跨请求持久化**的（cache_index.json），reset 后若参数/输入未变，
  运行时按 cache_key 命中缓存直接复用（增量设计）。「重置」要与「强制重算」语义
  区分，故新增 force 参数显式清缓存。

## 3. M7② 前端右键节点菜单

### 实现（FlowNode + Canvas）
- 节点 onContextMenu → 弹出上下文菜单
- 菜单项：
  - **▶ 单独运行**：selection 模式只重跑该节点（上游 cached 复用）
  - **⬇ 运行下游**：downstream 模式从该节点向后执行
  - **↺ 重置状态**：force=true 清缓存 + 本地画布同步 pending（下次运行强制重算）
- 菜单样式：深/浅色主题适配，失焦自动关闭，点击空白关闭

### API 客户端
- `api.resetNode(workflowId, nodeId, force=true)` 默认强制重算

## 5. 已知边界
- 重置仅影响单节点及其缓存；下游节点资产仍引用旧输出，需配合「运行下游」刷新
  （当前实现：重置后再点「运行下游」即可全链刷新）
- force 重置只清该节点 cache_key，上游缓存保留（合理：上游结果未变）
