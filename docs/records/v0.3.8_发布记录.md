## 7. 已知坑记录（本次新发现，建议补进规范 §8）

- **app-builder blockmap 无 `--output` 会污染输入文件**（新坑）：
  首次执行 `app-builder.exe blockmap --input=<exe>`（未给 `--output`）时，工具把 blockmap
  **原地追加进输入文件**（实测 exe 224,202,513 → 224,437,526，无 .blockmap sidecar 产出）。
  已用副本复现（副本 +235,304 ≈ blockMapSize+4，输入 hash 改变）。处置：重跑 makensis 生成干净
  安装包，并以显式 `--output=<exe>.blockmap` 重新生成（此时输入 hash 不变、sidecar 235,009 B 正常）。
  **教训：blockmap 命令必须 `--input=X --output=X.blockmap` 成对给出，切勿省略 --output。**
- **沙箱 %APPDATA% 写限制**：DSH 会话内冻结后端写 `%APPDATA%/FrameWeave`（templates/plugins.json）
  报 Permission denied（模板导入/插件契约同步跳过，不影响 health/user_nodes/seed）。真实桌面会话无此限制；
  验证时用 `APPDATA` 指向可写临时目录即可复现模板导入成功路径。
- S1-T9 环境治理测试（`test_backend_fw_dirs_subset_of_pending_list` /
  `test_cloud_db_and_pyarmor_log_removed`）仍按 0.3.7 惯例 deselect。
- 安装器/GUI 冒烟未在本 DSH 会话执行（沙箱阻断 GUI/安装器进程树，同 0.3.7）；安装包字节级有效
