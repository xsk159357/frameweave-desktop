
## 6. 商城筛选修复（2026-10-15）

根因：前端传递了 `kind` 参数，但本地 `cloud_gateway.cloud_market_items()` 未转发 `q/kind/official`，韩国云端 `cloud_server` 也忽略 URL 查询参数，所以筛选按钮只改变样式，列表仍显示全部 44 条。

修复：
- `cloud_gateway.cloud_market_items(q, kind, official)` 转发查询参数；
- 本地 `server.py` 将筛选参数传入 cloud gateway；
- 韩国 `cloud_server.py` 的 `market_list()` 实现 q/kind/official 过滤；
- HTTP GET `/api/market/items` 解析 query string 后传给 market_list。

线上验证：
- 全部：44 条（40 节点 + 4 工作流）
- `?kind=node`：40 条，全部 kind=node
- `?kind=workflow`：4 条，全部 kind=workflow
