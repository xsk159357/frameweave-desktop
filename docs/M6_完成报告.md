## 4. M6③ 隐藏 bug：PUT 保存丢弃运行时状态

### 症状
selection 重试失败：`RuntimeError: 需要源视频输入`；节点执行后状态/缓存一保存就丢

### 根因
`PUT /api/workflows/{id}` 重建 GraphNode 时**只带 id/type/x/y/params/inputs**，丢掉了
status / asset_ids / cache_key / error / progress。前端每次 run() 前先 saveWorkflow，
等于每次执行都把全图状态清成 pending、缓存资产清空、selection 重跑拿不到上游输出。

### 修复
PUT 重建时从旧节点继承运行时字段（status/asset_ids/cache_key/error/progress/started_at）。
