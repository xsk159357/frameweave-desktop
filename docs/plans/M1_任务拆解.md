# FrameWeave M1 任务拆解 — 核心闭环（文案→配音→字幕→成片）

> 目标：打通「一键出片」最小闭环：导入视频 → 场景检测 → AI文案 → TTS配音 → ASR字幕 → 字幕装配 → 剪映草稿/MP4 导出

## M1 节点清单

| 节点 | 类型 | 输入 | 输出 | 参数 |
|---|---|---|---|---|
| ai_narrate | 语义 | video(VIDEO), segments(SEGMENTS), script(SCRIPT,可选) | script(SCRIPT), narration(JSON) | mode(上帝视角/扩写/配画面/仿写), style, language, api_key, base_url |
| tts | 音频 | script(SCRIPT) | audio(AUDIO), marks(JSON) | engine(edge/indextts/cloud/manual), voice, rate, pitch |
| asr | 分析 | video(VIDEO) | subtitle(SUBTITLE) | model(small/base), language |
| subtitle_compose | 输出 | subtitle(SUBTITLE), script(SCRIPT) | styled_subtitle(SUBTITLE) | style(花字), font, color, animation |
| draft_export | 输出 | video(VIDEO), segments(SEGMENTS), audio(AUDIO), styled_subtitle(SUBTITLE) | draft(JSON), xml(STRING), edl(STRING) | format(剪映/PrXML/EDL), aspect(16:9/9:16) |
| model_download | 控制 | - | model(JSON) | repo(模型仓库), size |

## LLM 网关设计

- 协议: OpenAI 兼容 /v1/chat/completions（base_url 可配，默认 https://ameaaos.com/v1）
- 鉴权: Bearer Token（用户自带 Key，本机加密存储）
- vision: 视频抽帧（本地 ffmpeg）转 base64 送图 + ASR 文本 组合分析
- 流式: SSE 流式输出支持（M1 先同步）
- 失败重试: 3 次指数退避 + 可配置

## TTS 设计

- edge-tts: 免费多音色，M1 默认
- 本地克隆 IndexTTS2: M1 预留接口（需好显卡，M2 接入）
- 云端音色: 预留 provider
- 人工配音: 用户导入音频文件

## ASR 设计

- faster-whisper（ctranslate2，CPU 可跑）
- 模型下载: ModelScope 为主（keepitsimple/faster-whisper-small 等），HuggingFace 备用
- 输出: 字幕 JSON（每句 start/end/text）+ 可导出 SRT

## 剪映草稿导出

- 生成剪映草稿目录结构（draft_content.json）
- 时间线: 视频轨 + 音频轨 + 字幕轨
- 多格式: 剪映 JSON / Pr XML / EDL
