## 2. M3③ IndexTTS2 本地声音克隆

### 模型与环境
- 主模型 **IndexTTS-2.5**（index-tts/IndexTTS-2.5，官方 Bilibili 团队，1.1k+ 下载）：gpt.pth 3.1GB + codec.pth 579MB + s2mel.pth 396MB，共 **5.1GB**
- 辅助模型 **5.11GB**（w2v-bert-2.0 / semantic_codec / campplus / BigVGAN）
- 独立 Python **3.11.15** venv + torch 2.8.0+cu128（RTX 5060 Ti 16GB, sm_120）
- 支持中/英/日/西/阿 5 语，零样本克隆 + 情感向量 + 语速控制，输出 22050Hz

### 落地组件
| 组件 | 路径 | 说明 |
|---|---|---|
| 常驻服务 | backend/voice_clone/index_tts_server.py | FastAPI 8791，POST /synthesize 收文本+参考音频(base64)→返回 wav |
| TTS 集成 | backend/app/nodes/tts.py | engine=indextts：自动探测/拉起服务，audio_ref 参考音输入 |
| 参考音资产 | backend/data/ref_voice.wav | 音色库首个参考音（YunxiNeural 中性音） |
| 引擎资产 | @aid 直接引用 | engine.py 支持 "@资产id" 作为输入，素材库直连 |

### 关键工程点
- **wetext 中文路径坑**：kaldifst 用 ANSI 读 FST → GBK 乱码；复制 wetext 到 ASCII 路径 + PYTHONPATH 前置修复
- **服务自拉起**：首次用时 health 探测 → subprocess.Popen（3.11 venv）→ 等就绪 ≤300s；日志 backend/data/indextts_server.log
- **断点续传**：模型下载支持 Range（s2mel.pth 差 86MB 补下成功）
- 实测：模型加载 ~24s（一次），推理 8.6s → 6.91s 音频；工作流内 8.6s → 6.78s 音频

### 端到端验证结果
- 工作流 M3-IndexTTS克隆测试（TTS indextts + @参考音资产）→ **success，6.78s pcm_s16le 音频**
- 缓存失效：改文案 → 重新合成，新资产（634e4d3e82734fc4 ≠ 1dc1ef276be648ba）✅
- 缓存命中：参数不变 → 状态 cached、资产复用、8s 完成 ✅

## 4. M3④ Electron 后端捆绑（PyInstaller）

### 打包方案
- **frameweave-backend.spec**：onedir 模式，主程序 frameweave-backend.exe（17.7MB）
- **排除 torch 4.12GB**（后端不直接 import；IndexTTS 走独立 3.11 venv + HTTP）
- hiddenimports：edge_tts / faster_whisper + ctranslate2 / cv2 / uvicorn 全家组件 / app.nodes.* 全部 9 节点
- datas：voice_clone 服务脚本打入 _internal
- 产物 **454MB / 296 文件**（ctranslate2 60MB 含 CUDA libs）

### 三处必须的修复
1. **main.py 延迟导入**：uvicorn.run("app.server:app") 静态追踪不到 → 改 from app.server import app
2. **frozen 节点注册**：pkgutil.iter_modules 打包后失效 → autodiscover 白名单兜底（9 节点全量注册）
3. **数据目录**：__file__ 定位到只读 _internal → frozen 模式切 %APPDATA%/FrameWeave

### 打包后端独立验证
- health 200 / specs 9 节点 / edge TTS 工作流 → success，音频写入 C:\Users\Administrator\FrameWeave\assets（用户目录，非安装目录）✅
- IndexTTS 环境定位：源码 models/index-tts-code；打包 %APPDATA%/FrameWeave/indextts 或 INDEX_TTS_ROOT 环境变量

### electron-builder 集成
- extraResources 添加 backend-dist → resources/backend-dist/frameweave-backend.exe
- main.cjs 优先查找打包后端 exe（spawn 无参数），找不到回退 venv python
- 安装包 **FrameWeave-Setup-0.1.0.exe（209MB）**，NSIS 构建成功（全量访问沙箱下完成）
