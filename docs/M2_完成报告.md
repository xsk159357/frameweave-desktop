## 2. 关键实现

### video_render（MP4 渲染）
- ffmpeg（imageio-ffmpeg 自带二进制，无需系统安装）
- filter_complex 完成：逐段 trim + 缩放填充(force_original_aspect_ratio + pad) + concat / xfade 转场
- 字幕烧录并入同一 filter_complex（ASS 格式，支持花字/描边/字号/粗体，PlayResX 1920）
- 音频混入 aac + -shortest
- 画幅: 16:9 / 9:16 / 1:1；分辨率: 1080p / 720p / 4k

### batch_render（批量出片）
- manual_items 每行 `名称|文案` 定义矩阵；也支持 JSON items 输入
- 每项依次执行 edge-TTS + 字幕 + 渲染，结果汇总 JSON

## 4. 技术要点（踩坑记录）

- ffmpeg 同一输出流不可同时用 -filter_complex 与 -vf → 字幕烧录必须并入 filter_complex
- xfade 转场要求输入帧率一致：trim 后必须补 fps=30
- xfade 链输入顺序 [prev][next]，offset = 累积时长 - 转场时长(0.3s)
- 中文路径/文件名 ASS 路径转义（: → \:，' → \\'）
- ffmpeg 二进制来自 imageio_ffmpeg.get_ffmpeg_exe()（ffmpeg 7.1）
