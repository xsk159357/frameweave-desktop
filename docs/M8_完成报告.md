## 2. M8① 代码签名链路

### 实现
- `New-SelfSignedCertificate -Type CodeSigningCert` 生成本地签名证书（3 年有效期）
- 导出 pfx（密码保护）→ `certs/frameweave-dev.pfx`
- signtool 签名：`/fd SHA256 /tr http://timestamp.digicert.com /td SHA256`
  （嵌入可信时间戳，离线也能验证签名时间）

### 验证
- 主程序 + 安装包签名成功（带 DigiCert 时间戳）
- verify 显示完整证书链 + 时间戳，仅根证书不受信任（自签预期，真证书即消除）

### 重要发现
- **签名后必须重建 blockmap + sha512**：签名改变文件字节，electron-updater 的
  增量校验（blockmap/sha512）会失配 → 强制全量下载。publish 脚本已内置此步骤。
- signtool 需访问 CryptoAPI keyset（AppData 目录），沙箱下会报 ImportCertObject
  失败 → 发布需全量权限（或 CI 环境）。

## 3. M8② 一键发布脚本（scripts/）

| 脚本 | 功能 |
|---|---|
| `publish.ps1` | 打包（可 -SkipPack）→ 签名主程序+安装包 → 组装 release/<ver>/ → 重建 blockmap+sha512 |
| `serve_release.ps1` | 本地更新源服务器（python http.server，端口 8790） |
| `check_release.ps1` | 校验 latest.yml sha512 与安装包实际哈希一致（发布前自检） |

- 支持环境变量覆盖：FRAMEWEAVE_PFX / FRAMEWEAVE_PFX_PASSWORD / FRAMEWEAVE_SIGNTOOL
- 发布目录结构：release/<ver>/{FrameWeave-Setup.exe, *.blockmap, latest.yml}
- latest.yml 内安装包文件名固定为 FrameWeave-Setup.exe（更新源文件名不变）

## 5. 已知边界
- 自签证书不受 Windows 信任：SmartScreen 仍提示「未知发布者」（红条）。
  上真证书（OV/EV，CryptoAPI 信任）后：CSC_LINK / CSC_KEY_PASSWORD 环境变量
  即可让 electron-builder 自动签名，无需改代码。
- 更新源 URL 仍是占位域名，正式上线替换 update.example.com。
- blockmap 重建用 app-builder（electron-builder 自带），版本一致。
